添加节点

只写本地 nodes.yaml（先备份、写完立刻校验），不碰远端服务器。加完这里会多一行，部署再跑 ./vpskit apply <id>。
只写本地配置；不会 SSH、不会改远端。

告警邮件

节点上的 monitor 用它发告警。保存只改本地 nodes.yaml，要跑 ./vpskit apply <节点> 才会真正生效。
留空表示关闭邮件告警。

订阅链接

两个 client 是同一个节点的两套凭据：UUID 和订阅路径各自独立，轮换其中一个不影响另一个—— 平时一台设备用一个（手机用 main、备用机/Airport 用 client2），要换设备只换对应那条。
同一 client 下：Clash / Stash 是 YAML 订阅（Surge、Stash、ClashX 用）； v2ray / v2rayA 是 base64 的 URI 列表，里面含 IPv4 与 IPv6 两条，给软路由/v2rayN 用。
订阅里只有节点，没有分流/去广告规则：Clash 的规则在客户端规则集里，v2rayA 的规则在软路由自己配。
轮换路径：./vpskit rotate --sub <节点>
链接即凭据：谁拿到都能连。面板只在本机/局域网，节点的 8888 端口对外开放，别发群里。
